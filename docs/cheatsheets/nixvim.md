# Шпаргалка по Nixvim (Neovim на Nix)

Полнофункциональная среда разработки, собранная декларативно с помощью **Nixvim** в составе NixOS/Home-Manager конфигурации.

---

## 🚀 Концепция лидер-клавиши (`<Space>`)

Основной клавишей-префиксом (Leader Key) является пробел:
* `mapleader = " "`
* Все пользовательские команды сгруппированы логически вокруг `<Space>`.
* **Which-Key**: нажмите `<Space>` и сделайте паузу на доли секунды — появится интерактивное окно с подсказками по всем доступным комбинациям.

## 📂 Навигация по файлам и буферам

### 1. Файловый менеджер Oil.nvim
Oil позволяет работать с файловой системой так же, как с обычным буфером Neovim (редактирование, удаление, переименование строк = операции с файлами).
* `-` или `<Space>e` — открыть проводник Oil в текущей директории.
* Отображение скрытых файлов (dotfiles) включено по умолчанию.
* После переименования или создания строк выполните `:w`, чтобы применить изменения к файловой системе.

### 2. Нечеткий поиск (Telescope)
Быстрый поиск файлов, текста и метаданных с поддержкой fzf-native:
| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `<Space>ff` | Поиск файлов | `Telescope find_files` — быстрый переход к любому файлу в проекте |
| `<Space>fg` | Поиск по содержимому | `Telescope live_grep` — поиск строки по всему репозиторию |
| `<Space>fb` | Список буферов | `Telescope buffers` — просмотр и переключение между открытыми файлами |
| `<Space>fh` | Справка | `Telescope help_tags` — поиск по документации Neovim и плагинов |

### 3. Буферы и вкладки (Bufferline)
Вверху отображается панель вкладок/буферов с индикацией LSP-ошибок.
* `Tab` или `]b` — перейти к следующему буферу.
* `Shift-Tab` или `[b` — перейти к предыдущему буферу.
* `<Space>bd` — закрыть текущий буфер (`:bdelete`).
* `<Space>w` — сохранить текущий файл (`:w`).
* `<Space>q` — закрыть окно/выйти (`:q`).

## 🛠️ Работа с кодом и LSP

Подключены серверы: `nixd`, `pyright`, `bashls`, `ts_ls`, `rust_analyzer`, `marksman`, `lua_ls`, `clangd`, `gopls`, `jsonls`, `yamlls`, `html`, `cssls`.

| Клавиши | Назначение | Описание |
| :--- | :--- | :--- |
| `gd` | Go to Definition | Перейти к объявлению переменной / функции / типа |
| `gr` | References | Найти все использования символа через LSP |
| `K` | Hover Info | Показать документацию и сигнатуру типа под курсором |
| `<Space>cr` | Code Rename | Безопасное переименование символа во всём проекте |
| `<Space>ca` | Code Action | Быстрые действия, фиксы и рефакторинг |
| `[d` | Prev Diagnostic | Перейти к предыдущей ошибке/предупреждению |
| `]d` | Next Diagnostic | Перейти к следующей ошибке/предупреждению |

### Диагностика и всплывающие подсказки
* **lsp-lines.enable**: подробные сообщения об ошибках отображаются прямо в коде.
* **fidget.nvim**: ненавязчивый индикатор статуса LSP в правом нижнем углу.

### Автоформатирование (conform-nvim)
Форматирование выполняется **автоматически при каждом сохранении** файла (`:w` или `<Space>w`) с таймаутом 1000мс и LSP-fallback:
* **Nix**: `nixpkgs_fmt`
* **Shell/Bash**: `shfmt`
* **Python**: `ruff_format`, `black`
* **JS / TS / JSX / TSX / JSON / YAML / Markdown**: `prettier`

## 🌿 Git-интеграция

### Gitsigns
Маркеры изменений отображаются на полосе знаков (SignColumn): `+` (добавлено), `~` (изменено), `_` (удалено).
* `<Space>gg` или `<Space>hp` — предпросмотр текущего хунка (`preview_hunk`).
* `<Space>hs` — стейджинг текущего хунка (`stage_hunk`).
* `]h` — перейти к следующему измененному блоку.
* `[h` — перейти к предыдущему измененному блоку.

### Lazygit
В системе установлен CLI-инструмент `lazygit`. Из Neovim можно вызвать его через встроенный терминал или запустить по горячей клавише:
* Терминал в Neovim: `:terminal lazygit`
* В zsh-терминале: команда `lazygit`

## 🪟 Окна, сплиты и навигация

Стандартные сочетания окон Neovim с включенными `splitright` и `splitbelow`:
* `<C-w>v` — вертикальный сплит (окно справа).
* `<C-w>s` — горизонтальный сплит (окно снизу).
* `<C-w>h` / `<C-w>j` / `<C-w>k` / `<C-w>l` — переход между сплитами (влево, вниз, вверх, вправо).
* `<C-w>q` или `<C-w>c` — закрыть активный сплит.
* `<C-w>=` — выровнять размеры сплитов.

## 🎨 Особенности темы и оформления

* **Цветовая схема**: Нативная системная 16-цветная ANSI-палитра терминала (100% сопоставление с серым монохромным стилем Kitty). Сторонние теплые/желтые схемы (включая Gruvbox) полностью отключены.
* **Абсолютная прозрачность фона (`transparent = true`)**:
  - Переопределены подсветки (`highlightOverride`): `Normal`, `NormalFloat`, `FloatBorder`, `SignColumn`, `LineNr`, `StatusLine`, `EndOfBuffer`.
  - Фон полностью наследует параметры прозрачности и размытия Kitty/Alacritty/Ghostty без непрозрачных плашек и рамок.
* **Строка состояния**: `lualine.nvim` в строгом минималистичном стиле, использующем нативные ANSI-оттенки.
* **Автозакрытие скобок и комментарии**: `mini.pairs` и `mini.comment` (`gcc` — закомментировать строку, `gc` в visual mode).
