# Шпаргалка по Yazi (Терминальный файловый менеджер)

**Yazi** — молниеносный терминальный файловый менеджер на Rust с асинхронным движком, поддержкой превью изображений через Kitty Graphics Protocol и интеграцией с современными CLI-инструментами (`fzf`, `zoxide`, `ripgrep`).

---

## 🧭 Базовая навигация

| Клавиша | Действие |
| :--- | :--- |
| `h` / `←` | Перейти в родительскую директорию (на уровень выше) |
| `j` / `↓` | Спуститься на один пункт вниз |
| `k` / `↑` | Подняться на один пункт вверх |
| `l` / `→` / `Enter` | Войти в каталог или открыть файл (в Neovim/Nixvim по умолчанию) |
| `g` `g` | Переместиться в самый верх списка файлов |
| `G` | Переместиться в самый конец списка файлов |
| `Ctrl+u` / `Ctrl+d` | Прокрутка на пол-экрана вверх / вниз |

### Быстрый переход (`g`)
* `g` `h` — перейти в домашний каталог (`~`)
* `g` `/` — перейти в корень файловой системы (`/`)
* `g` `c` — перейти в каталог конфигураций (`~/.config`)
* `g` `d` — перейти в папку загрузок (`~/Downloads`)

## 📁 Управление файлами и буфер обмена

| Клавиша | Команда | Описание |
| :--- | :--- | :--- |
| `Space` | Select | Выделить/снять выделение с текущего элемента |
| `v` | Visual mode | Включить режим визуального блочного выделения файлов |
| `V` | Unselect all | Снять выделение со всех файлов |
| `y` | Yank / Copy | Скопировать выбранные файлы в буфер обмена |
| `x` | Cut | Вырезать выбранные файлы для перемещения |
| `p` | Paste | Вставить скопированные или вырезанные файлы в текущую папку |
| `d` | Trash | Переместить файл(ы) в корзину (безопасное удаление) |
| `D` | Delete | Полное безвозвратное удаление с подтверждением |
| `a` | Create | Создать новый файл или папку (завершите `/` для папки) |
| `r` | Rename | Переименовать текущий файл |
| `;` | Shell command | Выполнить shell-команду над текущим файлом |

---

## 🔍 Поиск, фильтрация и Zoxide

* `/` — запуск быстрого нечеткого поиска (`fzf` / внутренний фильтр по текущему списку).
* `f` — мгновенный фильтр (скрывает все элементы, не подходящие под ввод).
* `Z` — умная навигация через **zoxide** (введите часть имени папки из истории, и Yazi мгновенно перейдет туда).
* `Ctrl+s` — поиск содержимого через `ripgrep`.

---

## 📑 Работа с вкладками (Tabs)

* `t` — создать новую вкладку (открывается в текущей директории).
* `1` .. `9` — мгновенное переключение на вкладку с соответствующим номером.
* `[` / `]` — переход к предыдущей / следующей вкладке.
* `w` — закрыть текущую вкладку.

---

## 🚀 Открытие файлов и контекст

* `Enter` или `l` — запуск файла согласно mime-типу (текстовые файлы открываются в системном `$EDITOR` — `nixvim`).
* `o` — меню **Open With** (выбор приложения для запуска: консольный просмотрщик, GUI-редактор, mpv, браузер).
* `c` `c` — копировать путь к файлу в буфер обмена.

---

## 💡 Полезные шорткаты и справка

* `.` — показать или скрыть скрытые файлы (`dotfiles`).
* `~` — показать встроенную справку по всем горячим клавишам прямо в интерфейсе.
* `z` — свернуть/развернуть панель превью.
* `q` — выйти из Yazi.
